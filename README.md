# Projeto BD — Game Store

Um sistema de gerenciamento de uma loja de jogos digitais, desenvolvido em Python e integrado a um banco de dados PostgreSQL.

O projeto tem como objetivo aplicar conceitos de programação, modelagem de bancos de dados e operações CRUD, simulando o funcionamento básico de uma plataforma de venda de jogos.

## Sobre o projeto

O sistema permite o gerenciamento de usuários e jogos, oferecendo funcionalidades distintas para administradores e clientes.

A aplicação utiliza Python para implementar as regras de negócio e PostgreSQL para armazenar e gerenciar os dados, permitindo a integração entre as funcionalidades do sistema e o banco de dados.

## Tecnologias utilizadas

- **Python:** desenvolvimento da aplicação e implementação das funcionalidades.
- **PostgreSQL:** gerenciamento e armazenamento dos dados.
- **SQL:** criação, consulta e manipulação das tabelas.
- **Psycopg2:** conexão e comunicação entre Python e PostgreSQL.
- **Git e GitHub:** versionamento e gerenciamento do código-fonte.

## Funcionalidades

### Usuários
- Cadastro de clientes.
- Autenticação e login.
- Gerenciamento de contas.
- Consulta dos jogos disponíveis.

### Administrador
- Gerenciamento de jogos.
- Cadastro de novos jogos.
- Consulta dos jogos cadastrados.
- Atualização e remoção de registros.

### Carrinho de compras
- Adição de jogos ao carrinho.
- Remoção de jogos do carrinho.
- Visualização dos itens adicionados.

## Banco de dados

O PostgreSQL é responsável por armazenar as informações utilizadas pelo sistema.

A estrutura do banco de dados utiliza tabelas relacionadas por meio de chaves primárias (PRIMARY KEY) e estrangeiras (FOREIGN KEY), buscando manter a integridade e a organização das informações.
